## 最终训练参数（统计模型为拟合参数）

| 参数              | 实际设置                                                 |
| --------------- | ---------------------------------------------------- |
| 实现              | statsmodels.tsa.arima.model.ARIMA                    |
| 非季节阶数 (p,d,q)   | [0, 0, 0]                                            |
| 季节阶数 (P,D,Q,s)  | [0, 1, 0, 28]                                        |
| 拟合方式            | 31省分别拟合单变量模型                                         |
| 最终拟合样本数         | 1888                                                 |
| 拟合使用范围          | 训练集+验证集，测试数据不参与初始拟合                                  |
| 参数估计            | 极大似然；ARIMA接口的默认statespace方法                          |
| 优化重试顺序          | L-BFGS maxiter=300；未收敛则1000；仍未收敛则Powell maxiter=1000 |
| 实际最终优化设置        | lbfgs，maxiter=300：31省                                |
| 最终拟合收敛          | 31省均收敛                                               |
| 趋势项/平稳性约束       | 运行代码未显式覆盖，使用statsmodels默认值                           |
| 测试滚动更新          | append(refit=False)                                  |
| 预测步长            | 12天                                                  |
| 神经网络轮数、批量大小、学习率 | 不适用                                                  |

完整配置以 `effective_config.json` 为准；统计模型各省优化次数见 `final_fits.json`，神经网络逐轮记录见选中目录的 `epoch_history.csv`。

## 数据与评估设置

按原始时间顺序80%/10%/10%划分；训练1678行、验证210行、测试210行。测试逐日滚动，共199个预测起点，每个起点预测12天，汇总74,028个值计算误差；MAPE排除真实值为0的项。
